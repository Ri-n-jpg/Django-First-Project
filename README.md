## 🧠 How It Works

1. User enters text in the textarea.
2. Selects one or multiple operations.
3. Form sends POST request to `/analyze`.
4. Django processes text in `views.py`.
5. Result is displayed in `analyzed.html`.

---

## 🔐 Security

- Uses Django CSRF protection.
- Handles POST requests securely.
- Validates checkbox selections.
